# 计划书覆盖与上线门槛

更新时间：2026-08-26

## 已交付

- 单一 Vue + Go + MySQL 平台，多小组上下文与组级权限隔离。
- Excel 名单预览/导入、名单匹配注册、条款确认、管理员审批和 7 天待关注。
- 已有账号申请加入第二小组；一个账号只保留一个密码。
- Argon2id 新密码、旧 PBKDF2 登录后升级、登录/注册/上传限流、12 小时管理操作登录时效。
- 单组自动进入、多组切换和默认组；临时密码首次登录强制修改。
- 今日打卡、撤销、按组设置补卡期限、管理员补录/纠错、个人历史和游标分页。
- 三步式本周任务：周期、内容、预览发布；默认复制上一周、空白周、草稿和发布确认。
- 资源上传、站内鉴权、SHA-256 物理文件去重和组级元数据引用。
- 完成矩阵、小组设置、隐私开关、审计、平台概览、小组归档、单人重置和重复账号安全合并。
- 旧站只读扫描报告、迁移批次幂等数据表、备份/恢复演练/健康检查/30 并发脚本。
- Docker 日志滚动、健康检查、资源限制；数据、附件和备份目录均规划在 `/volume2`。

## 永久排除

严格按计划书 3.2：邀请码、名单外自由注册、原生 App、Redis/微服务/Kubernetes、公开社区/聊天、商业化、公开排行和复杂任务编排均不实现。

## 仍受上线门槛约束

以下不是代码缺失，而是必须经历真实运行时间或人工确认的上线条件：

1. 至少一个试点组连续运行 7 天。
2. 试点组成员、任务、打卡、得着和资源数量由组长核对确认。
3. 正式域名的群晖证书与 HTTPS 反向代理完成并验收。
4. 两次备份成功且至少一次空库恢复演练通过。

满足前述条件前，旧站点保持运行，不停止、不删除、不重定向。满足后也只先停容器，原目录只读保留至少 30 天。
