# 群晖 HTTPS 配置

应用容器仅在 NAS 上提供 HTTP 端口 `2980`，公网必须经群晖反向代理以 HTTPS 访问。

1. 在“控制面板 → 登录门户 → 高级 → 反向代理服务器”新增规则。
2. 来源使用正式域名、协议 HTTPS、端口 443；目标使用 `127.0.0.1`、HTTP、端口 2980。
3. 在“安全性 → 证书”申请/导入该域名证书，并把证书分配给新反向代理规则。
4. 开启 HTTP 自动跳转 HTTPS；不要把 MySQL 3308 暴露到公网。
5. 验证 `/api/health`、登录、上传和 Range 下载；浏览器不得出现混合内容。

切勿复用或覆盖其他站点的反向代理规则。正式域名确定前保留 2980 作为 NAS 内部验收入口，不宣称已完成 HTTPS 上线。
